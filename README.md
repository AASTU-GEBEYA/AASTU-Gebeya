### Your Campus. Your Marketplace.

**Group 9**

## 1. Project Overview

**AASTU ገበያ (AASTU Gebeya)** is a campus-focused digital marketplace and business discovery platform designed to connect the AASTU community with shops, cafés, student-owned businesses, and services available around the university.

The platform provides students with a convenient way to discover campus businesses, explore products and services, view café menus, compare prices, and find information about local sellers.

It also creates an opportunity for student entrepreneurs to showcase their businesses and reach more potential customers within the university community.

## 2. Project Objectives

The main objectives of AASTU Gebeya are to:

- Centralize information about shops, cafés, and student businesses around AASTU.
- Help students discover products and services available on campus.
- Provide accessible café menus and sample product catalogues.
- Promote student entrepreneurship and support small businesses.
- Improve communication between students and campus sellers.
- Create a user-friendly and organized campus marketplace experience.

## 3. Main Features

The website consists of six main pages:

| Page | Description |
|---|---|
| **Home** | Introduces AASTU Gebeya and highlights marketplace categories and featured businesses. |
| **Discover** | Provides a central directory for exploring cafés, shops, products, and student businesses. |
| **Shops** | Displays campus shops, product catalogues, and sample prices. |
| **Cafés** | Presents campus cafés, menu photographs, food and drink listings, and sample prices. |
| **Student Sellers** | Showcases student-owned businesses, products, and services. |
| **Sell With Us** | Introduces opportunities for student entrepreneurs to list their businesses. |

### Additional Features

- Business and product discovery.
- Café menu photo galleries.
- Product and menu price tables.
- Student business profiles.
- Search and category filtering in the full website version.
- Responsive interface for different screen sizes.
- Seller interest form demonstration.
- English and Amharic language selection concept.

## 4. Technologies Used

The project is developed using fundamental web technologies:

- **HTML5** — Website structure and content.
- **CSS3** — Layout, styling, responsiveness, and visual design.
- **JavaScript** — Client-side interactions, search, filtering, and form demonstrations.

The project focuses on vanilla HTML, CSS, and JavaScript without relying on frontend frameworks.

## 7. How to Run the Project

The website is a frontend project and does not require a backend server for its current demonstration.

1. Download or clone the repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder.
4. Locate `index.html`.
5. Open `index.html` using a web browser.
6. Navigate through the website using the navigation menu.

For development, any lightweight code editor and a modern web browser can be used.

## 8. Project Scope and Limitations

The current version focuses on frontend design, business discovery, and user interaction.

It does not currently include:

- User authentication.
- Database integration.
- Online payments or checkout.
- Live product inventory management.
- Actual seller account management.
- Backend processing of seller submissions.

The seller form is a frontend demonstration and does not permanently store submitted information.

Some business descriptions, prices, locations, opening hours, and contact details may be sample placeholders. These details must be verified and updated before real-world use.
